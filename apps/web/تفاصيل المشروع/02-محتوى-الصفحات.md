## 📍 الـ Layout العام (Dual Sidebar + Header)

### Primary Sidebar (الشريط الأيقوني الدائم — عرض 64px)
```
┌──────┐
│  🏠  │  → مركز القيادة (Command Center)
│  🏗️  │  → المشاريع (Projects Hub)
│  💰  │  → المالية (Financial Control)
│  👥  │  → الفريق (HR & Workforce)
│  🚜  │  → المقاولين (Subcontractors)
│  💬  │  → التواصل (Communication)
│      │
│      │  ─── فاصل ───
│      │
│  ⚙️  │  → الإعدادات (Settings)
│  👤  │  → الملف الشخصي (Profile)
└──────┘
```
- Tooltip عند hover على كل أيقونة يعرض اسم الوحدة
- أيقونة الوحدة النشطة: خلفية ملونة + شريط جانبي indicator
- بادج عداد على أيقونة التواصل (عدد الرسائل غير المقروءة)
- بادج عداد على المشاريع (عدد التحديثات المعلقة للمراجعة)

### Secondary Sidebar (الشريط الفرعي — عرض 260px — قابل للطي)
عند الضغط على أي أيقونة في Primary، ينزلق Secondary ويعرض:

**مثال عند اختيار 💰 المالية:**
```
┌────────────────────────┐
│  💰 الإدارة المالية     │ ← عنوان الوحدة
│────────────────────────│
│  📊 نظرة عامة           │
│  🔄 المطابقات           │
│  💳 المدفوعات           │
│  💼 العُهد              │
│  📄 المستخلصات          │
│  📈 تحليل الربحية       │
│  📉 التوقعات المالية     │
│────────────────────────│
│  🔽 طي القائمة          │
└────────────────────────┘
```

### Top Header (الشريط العلوي — ارتفاع 56px)
```
┌──────────────────────────────────────────────────────────┐
│  🔍 بحث شامل (Ctrl+K)  │  📊 اسم الصفحة   │  🌙 🌐 🔔(3) 👤 │
└──────────────────────────────────────────────────────────┘
```
- **البحث الشامل:** Command Palette — يبحث في: مشاريع، موظفين، دفعات، مقاولين
- **اسم الصفحة:** Breadcrumb: المالية > المدفوعات > مشروع فيلا النخيل
- **الأيقونات:** وضع ليلي/نهاري | تغيير اللغة | إشعارات (مع عداد) | صورة المستخدم + dropdown

## 📊 صفحات مركز القيادة (Command Center)

### الصفحة الرئيسية — `/dashboard`

**الصف الأول — 4 بطاقات KPI:**
| البطاقة | المحتوى | الأيقونة | اللون |
|---|---|---|---|
| مشاريع نشطة | العدد + نسبة التغير عن الشهر الماضي | 🏗️ | أزرق |
| إجمالي الإيرادات | المبلغ بالعملة + نسبة التغير | 💰 | أخضر |
| إجمالي المصروفات | المبلغ + نسبة التغير | 📤 | أحمر |
| صافي الربح | المبلغ + هامش الربح % | 📊 | ذهبي |

**الصف الثاني — رسمان بيانيان:**
| يمين (60%) | يسار (40%) |
|---|---|
| **منحنى الميزانية vs المنصرف** — Area Chart بخطين (مخطط/فعلي) مع فلتر زمني (شهر/ربع/سنة) | **توزيع حالة المشاريع** — Donut Chart (نشط/متأخر/مكتمل/متوقف) |

**الصف الثالث — عمودين:**
| يمين (50%) | يسار (50%) |
|---|---|
| **🚨 يحتاج انتباهك فوراً** — قائمة: تحديثات معلقة منذ X ساعة، مشاريع تجاوزت الميزانية، موظفين لم يسلموا تقاريرهم | **📊 أداء مقاولي الباطن** — Horizontal Bar Chart (التزام + جودة + تقييم) |

**الصف الرابع — عرض كامل:**
| المحتوى |
|---|
| **مؤشر التزام الموظفين اليومي** — جدول مصغر: اسم الموظف + المشروع + الحالة (✅ سلّم / ⚠️ متأخر / ❌ لم يسلّم) — آخر 7 أيام |

## 🏗️ صفحات إدارة المشاريع (Projects Hub)

### سجل المشاريع — `/dashboard/projects`

| العنصر | التفاصيل |
|---|---|
| **شريط أدوات** | زر "مشروع جديد" + فلاتر (الحالة/العميل/المدير) + بحث + تصدير |
| **الجدول** | اسم المشروع, العميل, مدير المشروع, الحالة (Badge ملون), نسبة الإنجاز (ProgressBar), الميزانية, المنصرف, الانحراف (أحمر لو سالب), تاريخ البدء, تاريخ الانتهاء المتوقع |
| **Row Expander** | الضغط يفتح: قائمة المراحل مصغرة (اسم المرحلة + نسبة الإنجاز + الحالة) |
| **إجراءات الصف** | فتح التفاصيل / تعديل / أرشفة |

### إنشاء مشروع جديد — Modal / Wizard

**خطوة 1: البيانات الأساسية**
- اسم المشروع, الوصف, النوع (تشطيب كامل/جزئي/إنشائي), الموقع
- تاريخ البدء, تاريخ الانتهاء المتوقع
- اختيار العميل (من القائمة أو إضافة جديد)

**خطوة 2: الميزانية**
- إجمالي الميزانية
- موعد تسليم التقارير اليومية (الساعة)

**خطوة 3: تعيين الفريق**
- اختيار مدير المشروع
- إضافة مهندسين + مشرفين + محاسب
- تحديد من يُطلب منه تحديث يومي

**خطوة 4: المراحل (اختياري — يمكن إضافتها لاحقاً)**
- إضافة مراحل مع: الاسم, الوصف, الوزن, الميزانية, التواريخ

---

### تفاصيل المشروع — `/dashboard/projects/[id]`

**8 تابات:**

**Tab: نظرة عامة**
- 4 بطاقات KPI: الميزانية الكلية, المنصرف حتى الآن, نسبة الإنجاز, أيام متبقية
- شريط تقدم كبير مع المراحل
- منحنى الإنجاز المخطط vs الفعلي (Line Chart)
- معلومات المشروع الأساسية (العميل, المدير, التواريخ)

**Tab: المراحل**
- قائمة المراحل كـ Cards أو Table
- كل مرحلة: الاسم, الحالة, نسبة الإنجاز, الميزانية, المنصرف, التواريخ
- أزرار: إضافة مرحلة / تعديل / تعيين مقاول باطن

**Tab: التحديثات**
- Timeline عمودي: كل تحديث فيه (التاريخ, المرسل, المرحلة, الوصف, الصور المصغرة, نسبة الإنجاز, الحالة)
- فلتر: حسب المرحلة / المرسل / الحالة
- الضغط يفتح التحديث الكامل مع الصور بالحجم الكامل + التعليقات

**Tab: الفريق**
- قائمة الأعضاء: الصورة, الاسم, الدور, التخصص, حالة التحديث اليومي
- أزرار: إضافة عضو / إزالة عضو

**Tab: المالية**
- ميزانية كل مرحلة vs المنصرف (Stacked Bar Chart)
- قائمة الدفعات المرتبطة بالمشروع
- إجمالي مستحقات المقاولين

**Tab: المقاولين**
- المقاولين المعينين على هذا المشروع
- لكل مقاول: المرحلة, المبلغ المتعاقد, المدفوع, المتبقي

**Tab: الملفات**
- Gallery مرتبة حسب المرحلة
- فلتر: صور / فيديو / مستندات
- معاينة مباشرة + تحميل

**Tab: الشات**
- غرف الدردشة المرتبطة بالمشروع

### مركز المراجعة (Review Inbox) — `/dashboard/projects/reviews`

- قائمة بكل التحديثات بحالة `pending`
- كل تحديث يعرض: المرسل, المشروع, المرحلة, الوقت, معاينة الصور
- **مؤشر زمني:** "معلق منذ 3 ساعات" (يتحول أحمر بعد تجاوز SLA)
- أزرار: ✅ اعتماد | ❌ رفض (يفتح modal لكتابة السبب) | 📝 طلب تعديل
- بعد الإجراء: التحديث يختفي من القائمة + إشعار للمرسل

## 💰 صفحات الإدارة المالية (Financial Control)

### النظرة المالية — `/dashboard/finance`
- 4 بطاقات: إجمالي الإيرادات, إجمالي المصروفات, صافي الربح, عهد معلقة
- Cash Flow Curve (Area Chart — الواردات vs الصادرات شهرياً)
- قائمة تنبيهات مالية: ميزانيات على وشك النفاد, عهد معلقة قديمة

### المطابقة الذكية — `/dashboard/finance/reconciliation`
- لكل مقاول على مرحلة:
```
┌─────────────────────────────────────────────────┐
│ مقاول: محمد أحمد (كهرباء)                       │
│ المرحلة: كهرباء الدور الأول — مشروع فيلا النخيل │
│─────────────────────────────────────────────────│
│ قيمة العقد:          100,000 ج                   │
│ نسبة الإنجاز المعتمدة:   60%                    │
│ المستحق فعلياً:       60,000 ج                   │
│ المطلوب من المقاول:   80,000 ج                   │
│ ⚠️ الفرق:            20,000 ج (دفع زائد!)       │
│─────────────────────────────────────────────────│
│ [✅ اعتماد المستحق 60,000]  [❌ رفض المطلوب]     │
└─────────────────────────────────────────────────┘
```

### المدفوعات — `/dashboard/finance/payments`
- جدول: التاريخ, المشروع, النوع (وارد/صادر), المبلغ, الطريقة, المسجل, الحالة
- إضافة دفعة جديدة: المشروع, المبلغ, النوع, الوصف, رفع إيصال
- فلتر: حسب المشروع / النوع / الفترة

### العُهد — `/dashboard/finance/petty-cash`
- جدول: الموظف, المبلغ, المشروع, تاريخ الفتح, الحالة (مفتوحة/تحت التسوية/مسواة)
- تنبيه للعهد المعلقة أكثر من 7 أيام
- عند التسوية: رفع الفواتير + المبلغ المتبقي

### تحليل الربحية — `/dashboard/finance/profitability`
- جدول: المشروع, إيرادات العميل, إجمالي المصروفات, الربح, هامش الربح %
- ترتيب من الأعلى ربحية للأقل
- تلوين: أخضر (ربح) / أحمر (خسارة)

## 👥 صفحات الموارد البشرية (HR & Workforce)

### سجل الموظفين — `/dashboard/team`
- جدول: الصورة, الاسم, الدور, التخصص, المشاريع المعين فيها, آخر دخول, الحالة
- أزرار: إضافة موظف / تعديل / تعطيل / Remote Wipe

### لوحة الصلاحيات — `/dashboard/team/permissions`
- مصفوفة تفاعلية: صفوف = موظفين, أعمدة = صلاحيات (Toggle Switch لكل خلية)
- Preset Roles: قوالب جاهزة (مهندس أول, محاسب متقدم)

### تعيينات المشاريع — `/dashboard/team/assignments`
- عمودين: الموظفون المتاحون (يسار) | المشاريع (يمين)
- سحب موظف إلى مشروع = تعيينه
- عرض حمل كل موظف (عدد المشاريع)
