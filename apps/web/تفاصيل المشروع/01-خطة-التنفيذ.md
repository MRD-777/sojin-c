# خطة التنفيذ — Enterprise ERP Dashboard

## المرحلة 1: البنية التحتية للوحة التحكم (الأساس)

### 1.1 إنشاء Layout النظام (Dual Sidebar + Header)
- **ملف:** `app/[locale]/dashboard/layout.tsx`
- إنشاء Primary Sidebar (شريط الأيقونات الرفيع الدائم)
- إنشاء Secondary Sidebar (القوائم الفرعية القابلة للطي)
- إنشاء Top Header (بحث شامل + إشعارات + لغة + ثيم + بروفايل)
- دعم RTL/LTR كامل
- حفظ حالة الـ Sidebar في Zustand + localStorage
- **التقنيات:** shadcn/ui Sidebar + Sheet + Zustand

### 1.2 نظام التنقل الديناميكي (Dynamic Navigation)
- تعريف هيكل القوائم لكل وحدة في ملف config مركزي
- فلترة القوائم تلقائياً حسب دور المستخدم (RBAC)
- Active state + Breadcrumbs
- Keyboard shortcuts (Cmd+K للبحث)

### 1.3 مكونات النظام الأساسية (Global Components)
- `StatCard` — بطاقة KPI (رقم + عنوان + أيقونة + نسبة تغير)
- `DataTable` — جدول متقدم (فرز + تصفية + بحث + pagination + row expander)
- `ChartCard` — حاوية رسم بياني (عنوان + فلتر زمني + الرسم)
- `StatusBadge` — شارة حالة ملونة (نشط/متأخر/مكتمل/ملغي)
- `ProgressBar` — شريط تقدم ملون حسب النسبة
- `EmptyState` — حالة فارغة مع رسالة ودية
- `SkeletonLoader` — تحميل وهمي لكل نوع مكون
- `ConfirmDialog` — حوار تأكيد للعمليات الحساسة

### 1.4 نظام الترجمة (i18n)
- إنشاء ملفات ترجمة لكل وحدة: `dashboard.json`, `projects.json`, `finance.json`, `hr.json`, `subcontractors.json`, `chat.json`, `settings.json`
- كل نص في النظام يمر عبر `next-intl` — لا نصوص مباشرة أبداً
